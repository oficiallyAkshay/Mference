Mference menu bar

A native Mac menu in the macOS 26 Liquid Glass style. Every row has an icon from Apple's SF Symbols set and a word. Every number is exact: it comes from the server, the installer or this Mac, never a guess. 24 states are drawn below. The figures are example readings; where a figure comes from the Mference docs, the footer says so.

The main menu

Status first. The top row names the model, its state and three measured facts: speed of the last reply, memory in use, and when and how fast it loaded.
Measured, not estimated. A load time is the last load of that model on this Mac. A model never loaded here says so, instead of a guess.
Native glass. Built with SwiftUI MenuBarExtra in menu style, so macOS draws the glass, the highlight and the dark mode. With "Reduce transparency" on, macOS draws a solid menu.
One accent. Colour appears only in the status tile: green ready, orange busy or warning, red failed, grey off.

Icons

The drawings here stand in for the SF Symbols named under each one. The build uses the real symbols, so they match the system and change with the theme.

Decided, 20 Nov 2026

Menu approved. "Open at Login" is off by default. The "Which Model Fits This Mac" guide ships in the first version.

Sketch only: not built, not run on a Mac. Figures from the Mference docs: Gemma 4 install 14.29 GB, Gemma 4 QAT 14.45 GB (needs 15.8 GB plus 1 GiB reserve while it installs), Qwen 3.6 19.55 GB, DeepSeek V4 Flash 91 GB on disk and 5.7 GB peak memory at 16 slots, Qwen 3.6 memory from 1.45 GB, Maple 645 MiB, the 86.4 s swap, the 2,940-token prompt and 210 prompt tokens/s on Flash-Next. All other figures (clock times, speeds, process numbers, free disk) are examples.
