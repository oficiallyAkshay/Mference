Memory

Only the experts a token needs sit in memory.

A mixture-of-experts model uses a few of its parameters per token. Mference keeps the shared core and a fixed set of expert slots resident, and streams the rest from SSD.

Limits

What it declines to be.

Not a wrapper

Each architecture is written out in Swift and Metal, with its own pinned checkpoint and quality gate. It does not sit on MLX or llama.cpp.

Not an app bundle

This is a source release for Apple Silicon Macs. It is not a signed app and it ships no weights. You install the pinned checkpoint you choose.

Not for the open internet

The server and the UI bind to your own machine, and the UI runs with no sign-in. Keep both ports off the network.
